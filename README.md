# 追程 · ScheduleTimeline

本地行程时间轴：把一天的演出与特典排进同一条时间轴，自动算空闲、找重叠、关联同团队日程。纯本地，无后端，数据不上传。

## 这是什么

追程（ScheduleTimeline）是一款面向线下活动场景的本地日程管理应用，主要服务于「演出」与「特典」两类行程。它用一条纵向时间轴把当天所有安排串起来——空闲时段、时间冲突一眼可见；同团队的演出与特典会自动关联，跨类型重叠的日程以双列并显，互不干扰。

所有数据保存在本机，不上传任何服务器。

## 核心功能

### 行程管理
- **两种日程类型**：演出、特典（前特 / 平特 / 终特）。演出绑定一个团队，特典可同时绑定多个团队。
- **团队自动关联**：同一天内，同名团队的演出与特典会互相展示关联，无需手工绑定。
- **团队候选**：支持从候选芯片快速选择，也能手动输入；特典可多选；长按即可删除候选。

### 时间轴视图
- **纵向时间轴**：当天行程按真实时间排序，空闲段自动标注。
- **重叠双列并显**：演出与特典时间重叠时，分别固定在两条独立轨道上，可各自点击编辑，不再交错缠绕。
- **按日浏览**：左右滑动切换日期，跟手位移、松手吸附；查看非当天时一键「返回今天」。
- **当前时间线**：今天页在左侧时间轴留白区显示一条红色短线 + 圆点，实时标出「现在」的位置；进入正在进行的时段时自动把该时间线滚到屏幕中央。进行中的日程用边框闪烁标出，时间重叠的冲突日程会一起闪。
- **概览 + 详情**：卡片只展示时间、团队/标题、类型等概览信息；地点、关联演出/特典、冲突提示与备注点开底部详情面板查看。特典详情可点「完成日程」，完成后不再提醒该日程。

### 提醒与通知
- **关键时间点提醒**：每项日程在开始前 3 天、当天 0 点、开始前 1 小时各主动提醒一次。特典被标记完成后不再提醒。
- **进行中持续展示**：开启「显示未来日程」后，通知栏持续显示当前进度与下一项倒计时；低版本自动回退为带计时与进度的持续通知。
- **系统原生呈现**：在 Android 16 上以 Live Updates 状态条呈现；在小米 HyperOS 3 上以超级岛（灵动岛）样式呈现。

### 外观
- 支持**浅色 / 深色 / 跟随系统**三种主题，设置后本地持久化。

### 桌面小组件
- **2×1 紧凑状态卡**：圆角卡片，展示当前进行中或下一项日程，一眼掌握状态；空档 / 已结束时只保留应用名 + 日期与核心状态，避免 2×1 高度下文字被截断。
- **4×3 今日日程列表**：圆角卡片 + 圆角列表项，列出当天全部日程，含时间、团队与类型标签。
- 与应用共享同一本地数据；日程变动后随通知一并刷新；颜色与圆角背景跟随系统夜间模式。
- 点击日程可直达对应事件编辑页：小卡点击进行中 / 下一项、列表点击任意项均直接打开编辑；冷启动与热启动均生效。

### 桌面快捷方式（App Shortcuts）
- 长按桌面图标可使用四个快捷入口：
  - **新增日程**：直接打开编辑页，固定为今天新增；
  - **今日日程**：一键回到今天的时间轴；
  - **最近日程**：跳到今天（含）起未来最近一个有日程的日期，无未来日程则停在今天；
  - **批量导入**：直达管理面板的 CSV 批量导入步骤。

### 导入导出
- **CSV 批量导入**：支持粘贴导入（可含日期列），兼容多种历史格式。
- **导出当日**：将当天行程导出为 CSV。
- **清空当日**：删除当前查看日期的全部日程，其他日期不受影响（不可恢复）。
- **一键清空**：删除全部日程与分类（不可恢复）。
