# 追程 · ScheduleTimeline

本地行程时间轴：把一天的演出与特典排进同一条时间轴，自动算空闲、找重叠、关联同团队日程。纯本地，无后端，数据不上传。

## 这是什么

追程（ScheduleTimeline）是一款面向线下活动场景的本地日程管理应用，主要服务于「演出」与「特典」两类行程。它用一条纵向时间轴把当天所有安排串起来——空闲时段、时间冲突一眼可见；同团队的演出与特典会自动关联，重叠日程按边界切片，同类型占整列、混合类型以固定双列并显。

所有数据保存在本机，不上传任何服务器。

当前版本：**1.14.1**（versionCode **29**）。

## 核心功能

### 行程管理
- **两种日程类型**：演出、特典（前特 / 平特 / 终特）。演出绑定一个团队，特典可同时绑定多个团队。
- **团队自动关联**：同一天内，同名团队的演出与特典会互相展示关联，无需手工绑定。
- **同时段自动合并**：同一天里，起止时间、类型、特典种类都相同的日程会合成一条，团队名用 `/` 连在一起。演出与特典时间重叠时仍分列显示。
- **团队候选**：支持从候选芯片快速选择，也能手动输入；特典可多选；长按即可删除候选。

### 时间轴视图
- **纵向时间轴**：当天行程按真实时间排序，空闲段自动标注。
- **重叠切片**：仅演出或仅特典重叠时使用全宽单列；演出与特典混合重叠时，分别固定在两条独立轨道上，可各自点击编辑，不再交错缠绕。任一列里互相重叠的那一段时间会单独成一块，列出涉及的日程，点某一条打开对应日程；不重叠的前后段仍是各自的卡片。卡片按实际文字高度保留至少一行时间与一行团队名，最高 320dp；空档比例高度最高 80dp，完整内容可点开查看。
- **按日浏览**：左右滑动切换日期，内容跟手位移，日期与「返回今天」随可见页同步，松手吸附；箭头短动画切日，「返回今天」、空日「最近日程」与日期选择立即定位目标日期。空日提示随日程变动更新。
- **当前时间线**：今天页在左侧时间轴留白区显示一条红色短线 + 圆点，实时标出「现在」的位置；进入正在进行的时段时自动把该时间线滚到屏幕中央。滚出视野后，左下角「当前时间」可立即跳回居中。进行中的日程用边框闪烁标出，时间重叠的冲突日程会一起闪。
- **概览 + 详情**：卡片只展示时间、团队/标题、圆形单字类型标（演 / 特）；地点、关联演出/特典、冲突提示与备注点开底部详情面板查看。特典详情可点「完成日程」，完成后不再提醒该日程。

### 提醒与通知
- **关键时间点提醒**：每项日程在开始前 3 天、当天 0 点、开始前 1 小时各主动提醒一次。同刻到期的多项日程一起处理；已安排但被系统延迟的提醒只在开场前补发，同一日程合并一次；新录入日程不补历史提醒。特典被标记完成后不再提醒，系统电量与权限策略可能延迟送达。
- **进行中持续展示**：开启「显示未来日程」后，通知栏持续显示当前进度与下一项倒计时；低版本自动回退为带计时与进度的持续通知。
- **系统原生呈现**：在 Android 16 上以 Live Updates 状态条呈现；在小米 HyperOS 3 上以超级岛（灵动岛）样式呈现。

### 外观
- 支持**浅色 / 深色 / 跟随系统**三种主题，设置后本地持久化。编辑草稿在旋转、主题变化和进程重建后恢复；保存成功后再返回时间轴。

### 桌面小组件
- **2×1 紧凑状态卡**：圆角卡片，展示当前进行中或下一项日程，一眼掌握状态；空档 / 已结束时只保留应用名 + 日期与核心状态，避免 2×1 高度下文字被截断。
- **4×3 今日日程列表**：圆角卡片 + 圆角列表项，列出当天全部日程，含时间、团队与类型标签。
- 与应用共享同一本地数据；日程变动后刷新；即使通知关闭，已放置的小组件仍在日程边界和跨日时独立更新；颜色与圆角背景跟随系统夜间模式。
- 点击日程可直达对应事件编辑页：小卡点击进行中 / 下一项、列表点击任意项均直接打开编辑；冷启动与热启动均生效。

### 桌面快捷方式（App Shortcuts）
- 长按桌面图标可使用四个快捷入口：
  - **新增日程**：直接打开编辑页，固定为今天新增；
  - **今日日程**：一键回到今天的时间轴；
  - **最近日程**：跳到今天（含）起未来最近一个有日程的日期，无未来日程则停在今天；
  - **批量导入**：直达管理面板的 CSV 批量导入步骤。

### 导入导出
- **CSV 批量导入**：支持粘贴导入（可含日期列），兼容多种历史格式；缺失、零时长或倒置时间会显示原始行号与原因；预览只能勾选有效条目再导入；第 10 列「完成」可保留特典完成态。
- **AI 提示词**：导入页可一键复制面向 AI 的提示词，连同时间表截图发给任意 AI 即可生成表格；粘贴回输入框可直接导入，AI 输出带说明文字或代码块也能识别。
- **导出当日**：将当天行程导出为 CSV。
- **清空当日**：删除当前查看日期的全部日程，其他日期不受影响（不可恢复）。
- **一键清空**：删除全部日程与分类（不可恢复）。
